## What

Create two new fixture directories testing multi-skill orchestrator routing — the gap that all 4 model reviewers independently flagged.

### `evals/signal-fixtures/review-redirect-create/`

Snapshot: task at `phase: review` with AI-passed review but one approver row at `status: pending` and a user rejection reply recorded in the dashboard decisions log. Asset `review_ai_pass: true`, `status: done`.

Trigger: `signal` redispatches `signal-review` because the user replied `reject: tone too casual` against the open approval gate.

Tests: `signal-review` returns `redirect target: create` AND `signal` then dispatches `signal-create`. The fixture covers two skill dispatches with an orchestrator routing step between them — the exact pattern the campaign-redirect-into-nonexistent-skill regression exploited.

Expected verdict: `redirect target: create` from `signal-review`.
Expected mutations: asset `status: needs-revision`, `review.md` approver row set to `rejected` with `rejected_reason`, `task.md` `phase: create`.

Includes complete `.signal/` snapshot, `expectations.md` with YAML frontmatter (`dispatch_skill: signal`, `ignore_fields`, `max_attempts`), expected verdict, and expected mutations.

### `evals/signal-fixtures/publish-done-archive/`

Snapshot: task at `phase: publish` with all assets `status: done`, `review_ai_pass: true`, `publish-log.md` with one `published` entry.

Trigger: `signal` advances after `signal-publish` returns `phase-complete`.

Tests: `signal-publish` detects all assets already published, returns `phase-complete`. `signal` advances to `done`, regenerates dashboard, moves folder to `.signal/archive/`. Covers the full terminal transition.

Expected verdict: `phase-complete` from `signal-publish`.
Expected mutations: `task.md` `phase: done`, dashboard regenerated with `Phase: done`, folder moves to `.signal/archive/`.

## Why

AC 7 — The existing 5 fixtures test single-skill dispatches. No fixture verifies that `signal` correctly routes between skills based on a verdict. The campaign-redirect-into-nonexistent-skill regression from T1 was precisely this kind of routing bug. All four model reviewers independently flagged orchestrator-level testing as the biggest gap.

## Done when

- Both fixture directories exist with complete `.signal/` snapshots that pass `run-signal-fixtures.sh` Layer 1 checks.
- Each `expectations.md` has YAML frontmatter with `dispatch_skill:`, `ignore_fields:`, and `max_attempts:`.
- `review-redirect-create` expectations describe the full `signal-review → redirect → signal-create` routing.
- `publish-done-archive` expectations describe the full `publish → phase-complete → done → archive` terminal transition.
